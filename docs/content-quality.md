# Content Quality

本项目的“内容质量”不只指经典原文是否齐全，还包括解释层是否自然、是否能帮助用户真正阅读结果。

## 目标

- 经典原文尽量完整
- 程序摘要避免模板味过重
- 动爻规则不只告诉用户“看哪里”，还要说明“为什么”
- 中文与英文都保持可读性，但允许阶段性深浅不同

## 当前分层

内容目前分成三层：

1. 原文层
- 卦辞
- 彖传
- 大象
- 爻辞
- 小象

2. 编辑说明层
- 面向阅读者的简洁解释
- 说明该卦更适合从什么角度理解
- 强调常见风险、节奏、方向感

3. 白话摘要层
- 面向一次具体起卦结果的程序化总结
- 结合本卦、动爻、变卦、体用关系

## 中文内容策略

中文当前优先做“解释质量”而不是只堆更多原文。

核心原则：

- 少用机械模板句
- editorial 要能说明卦的阅读重心
- 动爻规则要体现权重变化，而不是只报数量
- 摘要要像一段中文判断，而不是字段拼接

已完成的优化方向：

- 提升高频卦 editorial 深度
- 已完成三批中文高频卦 editorial 补强
- 强化动爻取用的中文说明
- 让摘要直接吸收 editorial 信息
- 清理中文摘要中的英文式空格和重复标点
- 修复 `case --lang en` 的语言传递缺口，避免内容层与界面语言脱节
- 清理英文摘要中的双空格与未翻译爻辞来源标注问题
- 扩充部分高频卦的英文 editorial 与 judgment / tuan / image

## 英文内容策略

英文当前优先做“关键卦深度覆盖 + 其它卦平稳回退”。

核心原则：

- 已翻译卦尽量给到 judgment / tuan / image / line_texts / line_images
- 未覆盖部分宁可提供稳定英文回退，也不要直接混入中文正文
- 先深后广，优先补核心高频卦

## editorial 写法约定

好的 editorial 不等于翻译原文，而是帮助理解原文。

推荐写法：

- 先指出该卦的核心主题
- 再说明判断时最该注意的方向
- 最后补一个常见误区或风险点

避免：

- 只把卦名换一种说法重复一遍
- 只写空泛价值判断
- 把现代建议写得过满，掩盖经典文本本身

## 动爻规则写法约定

动爻规则应包含三类信息：

- 当前变化数量意味着什么
- 本卦与变卦谁更重
- 读法顺序或判断重心在哪里

这比只写“看某爻”更有用。

## 后续优先级

建议按这个顺序继续推进：

1. 继续扩中文 editorial 覆盖面
2. 继续扩英文爻辞与小象翻译
3. 为不同起卦法补方法专属解释卡片
4. 让 Web 展示更多“文本如何被选中”的上下文
